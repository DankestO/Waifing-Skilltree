Libraries

Add the attributes and items of other mods here so you can pick them from lists. They are saved in this browser.

Attributes (JSON)

Formats: a list of ids, a list of {id,name,amount,operation}, an object {"mod:attribute":"Name"} or a file grouped by mod ({"mod":[{id,description}]}).

Items (one per line, or JSON)

Load textures: pick a folder with assets/<mod>/textures/item (a resource pack or an unzipped .jar). Icons are drawn in the editor and their ids are added to the item list.
