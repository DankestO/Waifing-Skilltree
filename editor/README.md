# Waifing Skilltree Editor

Single-page HTML editor for Waifing Skilltree trees. No install, no dependencies.

- Use it online: the `docs/index.html` page of this repository (GitHub Pages).
- Build it yourself: `python3 build.py` joins everything in `src/` into one `waifing_editor.html`
  (or `python3 build.py ../docs/index.html` to update the online page).
